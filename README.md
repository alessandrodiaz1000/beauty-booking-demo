# BE-LUCE Beauty Studio — Sito web

Sito mobile-first per **BE-LUCE Beauty Studio** (Montenero · Milano): manicure, pedicure, ceretta, semipermanente e trattamenti beauty con prenotazione online.

> **Nota per sviluppatori:** Real salon images/logos should only be used in a private demo or after permission from the business. For a public GitHub Pages demo, use generic or authorized assets.

## Avvio locale

```bash
npm install
npm run dev
```

Apri: **http://localhost:5173/beauty-booking-demo/**

## Build e deploy

```bash
npm run build
npm run deploy
```

Sito pubblico: **https://alessandrodiaz1000.github.io/beauty-booking-demo/**

## Asset

Logo in `public/assets/logo.png`. Nessun'altra immagine richiesta.

## Personalizzazione

- **WhatsApp, Google Maps, recensioni:** `src/utils.ts`
- **Servizi e copy:** `src/components/`
- **Colori:** variabili CSS in `src/App.css`
